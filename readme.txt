MetCraft is a drag-and-drop WordPress contact form builder that works inside Elementor or on its own with the standalone MetCraft Builder.

== Description ==

MetCraft is a flexible, design-friendly form builder for WordPress. Build beautiful forms without writing code using our visual drag-and-drop editor.

Works with Elementor - every field is an Elementor widget. Also includes a standalone builder for any theme or editor.

== All Features (Included) ==

* **Visual Drag-and-Drop Editor:** Build forms on a live canvas with Elementor.
* **Flexible Layouts:** Multi-column layouts with flexbox and grid.
* **Responsive Controls:** Adjust styles for desktop, tablet, and mobile.
* **Core Fields:** Text, Email, Number, Telephone, Date, Time, Select, Checkbox, Radio, Switch, Range Slider, Rating, File Upload, GDPR Consent, reCAPTCHA, Simple Captcha, Summary, URL, Password.
* **Conditional Logic:** Show/hide fields based on user input.
* **Multi-step Forms:** Break long forms into steps with navigation.
* **Calculation Fields:** Perform real-time mathematical calculations.
* **Quiz & Survey:** Score-based quizzes with result messages.
* **Payments:** Stripe and PayPal integration for collecting payments.
* **User Confirmation Email:** Auto email submitters after submission.
* **Export CSV:** Download form entries as CSV.
* **Mailchimp Integration:** Sync leads to Mailchimp audiences.
* **Required Login:** Restrict form submission to logged-in users.
* **Browser Data:** Capture visitor browser, platform, and IP info.
* **Hide Form After Submission:** Hide form once user submits.
* **Limit Entries:** Cap total form submissions.
* **Redirect After Submission:** Send users to a URL after submitting.
* **REST API:** Programmatic form access via REST endpoints.
* **WooCommerce Checkout:** Use forms as custom WooCommerce checkout.
* **Webhook:** Real-time data transfer to third-party URLs.
* **Email Verification:** Verify submitter emails before processing.
* **User Login/Registration:** Create WP user accounts from forms.
* **PDF Export:** Download individual entries as PDF.
* **Submission Rules:** Control who can submit based on roles, time, limits.
* **Form Templates:** Contact, booking, feedback, and calculation form templates.
* **Shortcode Support:** Embed forms anywhere with the [metcraft] shortcode.
* **AJAX Form Submission:** Submit forms without page refreshes.
* **Admin Notification Email:** Get notified when a form is submitted.
* **Saved Form Entries:** View and manage all submissions in the admin panel.
* **Form Analytics:** Track submission counts and performance.
* **Schedule Forms:** Set start and end dates for form availability.
* **GDPR Compliant:** Mandatory consent checkboxes for privacy regulations.
* **reCAPTCHA Integration:** Google reCAPTCHA v2 and v3 support.
* **Translation Ready:** Fully translatable with .pot file included.
* **HubSpot Integration:** Sync submissions to HubSpot CRM.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/metcraft` directory, or install through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. All settings are found in Admin sidebar -> MetCraft.

== Frequently Asked Questions ==

= What type of forms can I make? =
Contact forms, booking forms, feedback forms, application forms, survey forms, and more.

= Does it work with Elementor? =
Yes! MetCraft is built for Elementor. Every field is an Elementor widget with full styling control.

= Can I use it without Elementor? =
Yes! Use the standalone builder or the [metcraft] shortcode with any theme.

= Is reCAPTCHA supported? =
Yes, Google reCAPTCHA v2 and v3 are supported in the free version.

= Can I save form submissions? =
Yes, all submissions are saved in the admin panel and can be viewed, edited, and deleted.
